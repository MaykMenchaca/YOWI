Handoff — dirección "gimnasio"

Para pegar directo en tu HTML + Tailwind CDN. No requiere build.
1. Tailwind config (pégalo en cada página)
Reemplaza tu bloque actual de tailwind.config por este — agrega los tokens de marca.
<script>
  tailwind.config = {
    theme: {
      extend: {
        colors: {
          ink:    '#0B0F1A',   // negro/hero
          brand:  '#1F5FD9',   // azul primario (ya lo usan)
          lime:   '#8FD11F',   // acento energía — solo para datos/CTA
          paper:  '#F7F8FA'
        },
        fontFamily: {
          display: ['"Barlow Condensed"', 'sans-serif'],
          body:    ['"Barlow"', 'sans-serif']
        }
      }
    }
  }
</script>
<link href="https://fonts.googleapis.com/css2?family=Barlow+Condensed:wght@600;700;800&family=Barlow:wght@400;500;600;700&display=swap" rel="stylesheet">
2. Reglas de tipografía
  • Titulares (h1/h2/h3): font-display font-extrabold uppercase tracking-tight
  • Cuerpo de texto: font-body (peso 400–600)
  • Datos clave (gramos, %, stock): font-mono text-lime font-extrabold uppercase text-xs tracking-wide
  • Todo titular grande lleva una barra de acento debajo: <div class="w-14 h-1.5 bg-lime mb-6"></div>

4. Panel admin — solo 3 cambios
  • Títulos de sección: uppercase font-display border-l-4 border-lime pl-3
  • Botones "+Nuevo": cambiar de azul a bg-lime text-ink uppercase font-extrabold
  • Cards del dashboard: cambiar rounded-lg por rounded-none con border-l-[3px] de color por métrica (ya lo tenían, solo quitar el radio)
5. Orden sugerido de implementación
  1. Pega el config de Tailwind + fuentes en las 14 páginas (find & replace del bloque actual).
  2. Home (la nueva, no existía) — es la de mayor impacto.
  3. Header/nav — un solo include si tu PHP ya lo comparte entre páginas.
  4. Catálogo + Detalle de producto.
  5. Resto de páginas públicas (Marcas, Nosotros, Login, Registro, Pedido, Ofertas, Perfil).
  6. Admin (cambio menor, rápido).
  7. Sube tus fotos reales — reemplaza los placeholders bg-gray-100 por <img>.
